Comment l'installer ?
  1. Gmail : ⚙️ Paramètres › Voir tous les paramètres › Signature › Créer › collez (Ctrl+V), puis « Enregistrer les modifications » en bas de page.
  2. Outlook : Paramètres › Courrier › Composer et répondre › Signature › collez, puis Enregistrer.
  3. Apple Mail : Réglages › Signatures › « + » › collez. Sur iPhone : Réglages › Mail › Signature.
  4. Thunderbird : Paramètres des comptes › cochez « Utiliser HTML » › collez le code HTML.

Gmail n'accepte pas les images collées (photo, logo importé, icône) : elles peuvent disparaître. Avec le logo « Initiales » ou « Aucun », la signature est 100 % texte et s'affiche partout.

Faites scanner ce QR : votre carte s'ouvre sur le téléphone de la personne, avec le bouton « Enregistrer le contact ». Touchez le QR pour l'afficher en grand.
